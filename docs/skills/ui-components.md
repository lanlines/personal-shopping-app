# Skill: UI Components

## Purpose

Create reusable, presentational React Native components.

## Usage Rules

- No DB access inside components.
- Keep components small and focused.

## Conventions

- Props interface named <ComponentName>Props.
- Style via StyleSheet or a shared theme.

## Example Prompts

- Build a PriceRow component with name, unit, and price.
- Create an EmptyState component with icon and text.

## Mistakes to Avoid

- Mixing business logic into UI.
- Adding navigation logic inside a reusable component.
