# Skill: API Integration (Future)

## Purpose

Prepare for optional sync or export features after MVP.

## Usage Rules

- No network calls in MVP.
- Keep API modules isolated in src/api.

## Conventions

- Use typed request and response models.
- Convert API data to internal types in a mapper.

## Example Prompts

- Add an export endpoint module for transactions.
- Create a sync queue abstraction (future).

## Mistakes to Avoid

- Mixing network code into repositories.
- Adding API code before MVP scope.
