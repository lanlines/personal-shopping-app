# Skill: Form Handling

## Purpose

Implement simple forms for creating and editing entities.

## Usage Rules

- Use basic React state for MVP.
- Validate required fields and numeric inputs.

## Conventions

- Validation functions in feature domain folder.
- Submit uses repository use case.

## Example Prompts

- Build a Store form with name and notes.
- Add validation for price and quantity.

## Mistakes to Avoid

- Introducing heavy form libraries.
- Skipping input validation.
